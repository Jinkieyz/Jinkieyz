# Nadeschda Barenje

Artist working with glass, code, and ceramics. BA Ceramics and Glass, Konstfack 2026.

I train AI models on my own artwork, write code that generates organisms, and cast the results in glass using lost-PLA and hot blowmold techniques with gypsum-quartz molds.

## Current work: Hard Copy

My degree project at Konstfack explores what happens when 7843 photographs of my own sculptures are fed into neural networks trained from scratch. The trained models produce new images that I then materialize back into physical glass objects, closing a loop between code and craft.
